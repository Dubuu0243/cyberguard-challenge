# ⚡ Quick Deployment Checklist

Follow these steps to go live in 10 minutes:

## 1️⃣ Create GitHub Repo (2 mins)
- [ ] Go to https://github.com/new
- [ ] Name: `cyberguard-challenge`
- [ ] Make it **Public**
- [ ] Click "Create repository"

## 2️⃣ Upload Files (3 mins)
Choose ONE method:

### Method A: Git Command (Fastest)
```bash
cd cyberguard-challenge
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/dubuu0243/cyberguard-challenge.git
git push -u origin main
```

### Method B: GitHub Web UI
1. Go to your new repo
2. Click "Add file" → "Upload files"
3. Drag & drop all files
4. Commit

## 3️⃣ Deploy to Vercel (3 mins)
- [ ] Go to https://vercel.com
- [ ] Click "Sign up" → "Continue with GitHub"
- [ ] Authorize Vercel
- [ ] Click "New Project"
- [ ] Select `cyberguard-challenge`
- [ ] Framework: "Create React App"
- [ ] Click "Deploy"

## 4️⃣ Get Your Live Link
- [ ] Wait 1-2 minutes for build
- [ ] Copy the generated URL (e.g., `cyberguard-challenge.vercel.app`)
- [ ] Test it works
- [ ] Share it! 🎉
