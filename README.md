# CyberGuard Ghana Security Challenge

Interactive scam detection quiz with downloadable certificate. Built for youth in Ghana to learn about common scams and earn their official CyberGuard certification.

## 🚀 Quick Deploy to Vercel (2 MINUTES)

### Step 1: Create GitHub Repository
1. Go to https://github.com/new
2. Name it: `cyberguard-challenge`
3. Click "Create repository"

### Step 2: Upload Files to GitHub (Using Web Interface)
1. In your new repo, click "Add file" → "Upload files"
2. Download all files from this folder
3. Drag & drop them into GitHub
4. Commit with message: "Initial commit"

### Step 3: Deploy to Vercel
1. Go to https://vercel.com
2. Sign in with GitHub
3. Click "New Project"
4. Select `cyberguard-challenge` repository
5. Click "Deploy"
6. **Done!** Vercel will give you a live URL in ~30 seconds

Your app is now live! 🎉

### Example URL
`https://cyberguard-challenge.vercel.app`

## 📋 Features

- 5 interactive scam detection questions
- Real-world scenarios from Ghana
- Personalized certificate with tier badges
  - 🎖️ 60%+ = Scam Spotter
  - 🔍 80%+ = Scam Detective  
  - 👑 100% = Scam Master
- Downloadable PNG certificate
- Responsive mobile-friendly design
- Gamified UI with progress tracking

## 🎯 Scams Covered

1. **Romance Scams** - Fake modelling scouts, love interests
2. **Phishing** - Fake bank/account warning emails
3. **Job Scams** - Fake recruiters asking upfront payment
4. **Dating App Scams** - Requests for sensitive personal info
5. **Password Security** - Safe practices
